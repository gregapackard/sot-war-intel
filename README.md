# Cloudy’s SoT War Room

Hosted War Intel exporter for SoT – Torn City Original.

## Install
1. Enable GitHub Pages for this repository using the `main` branch / root.
2. Install `Cloudys_KAL_Bridge.user.js` in Tampermonkey once.
3. Open `https://gregapackard.github.io/sot-war-intel/`.
4. Enter Torn, FFScouter, and KAL-connected public Torn keys and run the scan.

Credentials are used in-browser and are not intentionally included in exported JSON.
